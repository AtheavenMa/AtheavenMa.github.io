Questions

What is OpenSAE?

An open research organization building tools for mechanistic interpretability. SAEBase is our main software platform.

Can I use SAEBase now?

Yes. The code and Python tools are open. This website’s Workspace is a prototype; it shows examples but does not run models.

Can I contribute to SAEBase?

Yes. Fork the repository and open a pull request.
