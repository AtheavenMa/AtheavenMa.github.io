# SAEBase Atlas publication

The public SAEBase Atlas is generated from the source-owned `OpenSAE/SAEBase` repository and deployed independently from OpenResearch.

- Source commit for the current verified generated snapshot: `c7e38a575699d4cd03ebedc94145cc8ed7ce6d85`.
- Public Code Tree: **282 independent visible research/interface nodes**. The complete original source inventory remains available in the expandable interface panels with original IDs, signatures, and provenance.
- Semantic acceptance: the source generator and CI reject globally repeated Code titles, summaries, synonymous actions across different parents, generic boilerplate, and sibling collisions. The verified audit contains **zero issues**.
- Validation: five-tree bilingual checks, Chromium browser tests and source-backed interface retention checks passed in the isolated SAEBase publication workflow.
- Site deployment: publication commits may use the Actions token and therefore need a subsequent ordinary site change that triggers the separate `Deploy site` workflow; check the deployment result rather than assuming a successful snapshot commit guarantees an updated website.

This publication record is deliberately outside `atlas/` so a site deployment can include the already verified generated snapshot without regenerating it again.
