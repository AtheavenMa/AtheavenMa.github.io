Open SAEBase ↗

Build with SAEBase.

Python tools and an HTTP API for research workflows.

Start locally

git clone --branch feat/wp15-six-workflows https://github.com/OpenSAE/SAEBase.git
cd SAEBase
python -m pip install -e ".[analysis]"
python examples/interventions/pythia_feature_edit.py

Read the API

Start the Research Lab backend, then browse models and results.

python -m pip install -r apps/research-lab/requirements.txt
cd apps/research-lab
uvicorn backend.api:app --host 127.0.0.1 --port 8000
curl http://127.0.0.1:8000/api/health
curl 'http://127.0.0.1:8000/api/sites?limit=5'
curl http://127.0.0.1:8000/api/explore/traces
curl http://127.0.0.1:8000/api/wp15/benchmark
Connect the Workspace ↗

Explore features

Capture a prompt on a machine with the model and SAE installed.

python scripts/wp12_p2_capture.py \
  --prompt-file prompt.txt --sae-key gemma270m_scope_resid \
  --layer 5 --device cuda --sample-id sample-01 \
  --group-id group-01 --output trace.json

Open trace.json in the Workspace to inspect its tokens and features.

curl -X POST http://127.0.0.1:8000/api/explore/search \
 -H 'Content-Type: application/json' \
 -d '{"mode":"explanation","query":"number","limit":5}'

Intervene

The public API validates edits; actual compute uses the private worker.

curl -X POST http://127.0.0.1:8000/api/jobs/preflight \
 -H 'Content-Type: application/json' \
 -d '{"site_id":"YOUR_VERIFIED_SITE","text":"Example prompt", "operation":"ablate", "feature_ids":[1819], "strength":1, "max_new_tokens":0}'

Operator-only execution: POST /api/private/inputs, then POST /api/private/jobs, then GET /api/private/jobs/{job_id}/result. Requires a configured GPU worker and operator token.

Generate

python scripts/wp15_steer.py \
  --prompt-file prompt.txt --sae-key gemma270m_scope_resid \
  --layer 5 --device cuda --max-new-tokens 16 \
  --scale 2 --output generation.json

Evaluate

JAXTYPING_DISABLE=1 python scripts/m3_native_saebench_smoke.py

Train

Use saebase.wp12.training.TrainPlan and run_training with a compatible local model and dataset. Load the trained checkpoint before using it.

Interpret

python scripts/wp12_autointerpret.py \
  --local-model /path/to/model --examples feature.json \
  --output candidate.json --device cuda

Interpretation candidates require review before publication.
